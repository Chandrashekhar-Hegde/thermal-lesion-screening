# Security

Do not open a public issue for a vulnerability or accidental sensitive-data exposure.
Use [GitHub's private vulnerability reporting](https://github.com/Chandrashekhar-Hegde/thermal-lesion-screening/security/advisories/new).

Include the affected version or commit, impact, reproduction steps, and any proposed
mitigation. Do not attach clinical images, DICOM files, credentials, or patient
identifiers.

This project is research software and must not be used for patient care.
